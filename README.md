\# 📖 AI Literary Novel Translator (RU)



Инструмент для ai cat type художественного перевода электронных книг из формата `.epub` в `.epub` на русский язык с использованием современных LLM через OpenRouter.


\## ✨ Возможности

\- \*\*Полный цикл EPUB $\\to$ EPUB:\*\* извлекает текст глав, переводит и собирает готовую электронную книгу с оглавлением (TOC) и стилями.
