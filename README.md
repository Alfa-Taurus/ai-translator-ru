\# 📖 AI Literary Novel Translator (RU)



Инструмент для двухпроходного (\*\*2-Pass\*\*) художественного перевода электронных книг из формата `.epub` в `.epub` на русский язык с использованием современных LLM через OpenRouter.



\---



\## ✨ Возможности



\- \*\*Полный цикл EPUB $\\to$ EPUB:\*\* извлекает текст глав, переводит и собирает готовую электронную книгу с оглавлением (TOC) и стилями.

\- \*\*2-Pass пайплайн:\*\*

&#x20; - \*\*Pass 1:\*\* генерация контекста сюжета и извлечение имен/терминов в глоссарий.

&#x20; - \*\*Pass 2:\*\* художественный перевод с учетом накопленного контекста.

\- \*\*Auto-Retry:\*\* автоматический повтор запросов при сетевых ошибках или таймаутах.

\- \*\*Два режима:\*\*

&#x20; - 🖥️ \*\*Web-GUI:\*\* локальный интерфейс в браузере (Gradio).

&#x20; - ⚙️ \*\*CLI:\*\* быстрый запуск через консоль.



\---



\## 🚀 Быстрый старт



\### 1. Установка зависимостей



```bash

git clone \[https://github.com/Alfa-Taurus/ai-translator-ru.git](https://github.com/Alfa-Taurus/ai-translator-ru.git)

cd ai-translator-ru

pip install -r requirements.txt

```



\### 2. Запуск Web-интерфейса



```bash

python app.py --gui

```



\### 3. Запуск через CLI



```bash

python app.py --file "book.epub" --key "sk-or-v1-..." --model "qwen/qwen3.7-flash"

```
